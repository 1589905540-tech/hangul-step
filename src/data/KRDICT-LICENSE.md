The export selects Chinese translation lemmas, normalizes surrounding whitespace
and Unicode NFC, omits empty lemmas, non-translation placeholders, and Chinese
lemmas longer than 120 characters, and arranges
the text into a compact index. The extraction script can also produce separate
source entries; those detailed entries are not bundled with the application. It does not export
audio, images, other multimedia, or example sentences.
Media on the publisher's website may have separate licenses and are not covered
by this text-data export.

The license notice concerns the dictionary data, not independently authored
application code. `krdict-source.json` records the input checksum, extraction rules,
counts, and output checksums.
