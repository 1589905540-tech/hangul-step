# 春 · 韩语生词本

面向 iPad 触摸使用的网页试用版。输入韩文或中文，自动查找对应释义，确认后加入自己的生词本。只学习用户主动添加的词，每组最多 10 个；先用可跳过的词卡认识不熟的词，再双向四选一。词卡自评为“认识／模糊／不认识”，点击后展开中文，“记错了”可纠正自评，模糊和不认识的词优先进入本轮练习。自评只影响本轮顺序，不计答对、不写入熟悉度。答错或选择“不认识”会显示配对并安排间隔三题重练，末尾不足三题时缩短间隔；每词每方向自动重练最多一次，整组最多 40 题。结果可专练待巩固的词。

参考用户提供的不背单词截图重做首页、回忆词卡和答题反馈：原创水彩海岸背景，柔和灰绿桃色渐变，大字号单词、半透明例句和词组卡、底部三档自评。首页移除签到日期块，保留单屏学习／复习入口和底部导航，学习小组移至生词本。卡片淡入和换词轻移会响应系统“减少动态效果”设置；换页和答题防重复点击。20 个常用词有原创并核对的例句、词组，只在用户确认的释义与内置词义匹配时显示；自定义释义没有匹配内容时只显示用户释义。背景生成提示、方法与文件见 [docs/design-assets.md](docs/design-assets.md)。

每次重新抽取干扰项，优先随机选择至多两个同类或近形词，再从完整候选池随机补足，最后随机排列。排除相同词、已识别的同义项和重复释义；个人词库候选先去重，个人释义优先。有替换候选时避免连续同题使用相同组合，并避免正确位置连续相同。浏览器保留最近 300 套选项排列偏好；词库和进度以设备 IndexedDB 记录为准。内置常用词只作干扰项，不会自动加入生词本。自定义词尚无语义类别时使用近形词与随机补足，不宣称所有输入都有语义相似词。

设备从已保存的学习状态推导复习安排：双向完成后先 1 天，后续隔天双向首答正确可延长为 3、7、14 天；同一天反复练不会提升级别，任意方向答错会重置级别。尚未双向答对的已练词可立即巩固。此为本产品的简化规则，不宣称复现百词斩的专有算法。到期复习每次最多 10 个，只针对个人词库。

查词使用下载到设备的韩国国立国语院韩汉词典索引，来源为 2026-09-19 公开数据，包含 48,308 个韩文词头、68,109 条中文义项。韩文或中文可双向查找，多义候选选择本次要记的意思。未收录的内容可手动填写；当前界面不调用在线翻译服务。释义可以编辑，词典不会自动加入生词本。

词典数据按 [CC BY-SA 2.0 KR](https://creativecommons.org/licenses/by-sa/2.0/kr/) 提供。公开路径 `/dictionary-license` 展示来源与许可，`/krdict-ko-zh-202609.json` 提供派生 JSON，`/krdict-source.json` 提供来源、加工说明与校验信息。重新分发或改编这些词典数据需保留署名与相同许可；该许可适用于词典数据。

无需 GPT 登录。词库和每次答题保存在设备 IndexedDB；保存失败不会允许进入下一题。重复保存同一答案不会多记错题，另一标签修改词义后旧题不会影响新释义。长期本地练习自动压缩记录，避免无界答案日志。当前上限 1,000 词，超限明确拒绝保存而不清空已有库。

iPad 与 iPhone 暂不自动同步。右上角“备份”可以导出 JSON、在另一设备导入，新词及进度会加入，已有韩文不被覆盖。备份错误会回滚整次导入。设备清理浏览器数据可能移除词库，请定期导出。Service Worker 完整缓存静态资源后可离线打开和练习；个人 API 响应不被缓存。

旧版服务器保留兼容 API 和数据库，新界面仅在迁移时读取旧库。首次升级尝试将词和已有学习进度复制到设备；失败时可在“备份 → 导入原词库”重试或填写旧学习码。此后新词与答题仅写设备。同步协议及 uniCloud 适配器已预备但未接入当前界面、未创建实际云资源，SDK 事务只通过模拟测试。

首次需要联网打开 HTTPS 页面并准备离线资源。Safari“分享 → 添加到主屏幕”后使用，安装入口与 Safari 词库应自行确认，必要时通过备份迁移。发音直接读取国立国语院原站录音，不需要购买个人服务器或云存储；只有 playing 事件后才显示播放中。索引覆盖 41,389 个词头，同形词按个人释义匹配，苹果／道歉分别使用不同 사과 录音。没有重托管或批量打包音频；可在设备缓存最近听过的最多 20 条录音，iOS opaque Range 仍可能需要联网。未收录录音时尝试设备韩语语音；例句只在检测到韩语系统语音时显示按钮。失败提供当前页面重试，切换词或退出会停止。国内免 VPN 的音源访问、实体 iPad 音频与原生 iOS 安装包尚未验证。公开元数据及来源仍保留。

当前本地版使用说明见 [iPad本地版说明.md](iPad本地版说明.md)。`node scripts/build.mjs` 同时构建 Worker 兼容版本和 `dist/public/` 静态版本；后者无需数据库服务。`node scripts/preview-local.mjs` 可预览静态版，`scripts/package_local.py` 输出不含私人词库的本地发行包。

## 本地运行

界面以可视视口为一屏：查词输入与释义确认切换显示，背词和答题操作留在底部；生词本用学习组选择和分页浏览，结果中的待巩固词也可翻页。长词、长释义和长选项提供“全文”分页阅读，回忆阶段全文仅显示韩文，避免提前透露答案。手机键盘出现时压缩表单并收起导航。桌面 Edge 已模拟 375×568、360×640、375×667、390×844 和 844×390 检查操作可达性；这不等于实体 iPhone Safari 验证。

Node.js 24 或更高版本（本地预览使用内置 SQLite）。

```powershell
npm install
npm run db:generate
npm run dev
```

开发预览使用 `.dev/learning.sqlite` 和预览用户。正式独立运行不需要安装任何运行依赖：先 `npm run build`，再 `npm start`。独立运行使用 `data/learning.sqlite`，支持完全免登录的多个学习空间，忽略客户端伪造的 GPT 身份头。再次启动会读取原数据库。

`scripts/package_standalone.py` 生成 `release/春-免GPT登录独立版.zip`，只包含已构建应用、Node 服务、数据库迁移和部署说明，不含私人词库、凭证、Git 元数据或开发依赖。构建会将词典索引、来源许可页与来源信息嵌入 `dist/server/index.js`，随应用一同打包，运行后可通过上述公开路径读取；发布时应保留这些许可与数据入口。

## 验证

```powershell
npm run build
npm run validate
npm test
```

`tests/` 验证分组和双向四选一、相似候选、连续组合与位置变化、有限间隔重练、复习间隔增长与答错重置、翻译失败、词库 CRUD、空间隔离、答题幂等、学习码跨浏览器恢复、无效码不改变身份、旧账户迁入，以及独立服务重启后的磁盘数据持久化。受限环境不能启动测试子进程时可运行 `node --test --test-isolation=none tests/*.test.mjs`。

`scripts/browser-check.mjs` 使用已安装的 Edge 和 Playwright 检查 1024×1366 与 390×844 的界面、三档自评及记错纠正、10 张词卡不记为答对、困难词优先、换词连续点击防护、系统减少动态效果、不同自定义词义不显示错误例句、20 道双向题与一道间隔错题重练、重练选项改变、“不认识”、刷新后的进度、保存失败重试、第二浏览器恢复相同学习码、共享复习安排及回到页面自动更新。设置 `PLAYWRIGHT_MODULE` 为本地 `playwright/index.mjs` 的绝对路径后运行；截图和机器可读报告放在忽略的 `artifacts/`。这是桌面浏览器的 iPad 尺寸模拟，尚未在实体 iPad Safari 上验证。

页面对 WebMCP 做能力检测，支持时注册只读查词工具。当前环境没有原生 WebMCP 浏览器上下文，未宣称该工具通过原生验证。

## 发布

新增 `scripts/viewport-check.mjs` 验证手机竖屏／横屏各学习状态一屏布局、全部生词分页可达和长内容全文阅读；`scripts/lookup-state-check.mjs` 验证键盘下的表单以及恢复空间遇到读取失败、旧查词延迟返回时的状态。两者需要本机测试服务器和 `PLAYWRIGHT_MODULE`，只请求 `http://127.0.0.1:4178`，结果写入 `artifacts/`。

`.openai/hosting.json` 记录原有 Site 与逻辑 DB 绑定；按 Sites 工作流发布。用户请求免登录后页面访问可设为公开，个人词库仍由不可猜测的学习码隔离。国内独立部署见 [国内部署说明.md](国内部署说明.md)。网站免登录不代表已在中国大陆部署或验证网络可达。

数据库变更由 `db/schema.ts` 及生成的 `drizzle/` 迁移管理，不在请求期间自动建表。已发布迁移保持不可变。部署独立版时必须保留数据目录；换托管平台时需迁移数据库，学习码本身不包含词库数据。
